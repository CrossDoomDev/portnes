# PortNES — самостоятельный перенос на JavaScript

Игра на HTML/CSS/JavaScript с новой графикой и музыкой. В ветке `native-port` работают общий цикл, управление корпусом и башней, оружие и запасы, враги, боссы, урон, карты, маршруты, меню, вступление, пароли, радио и финальные титры. Полное прохождение всех развилок и исчерпывающее совпадение с оригиналом пока не подтверждены.

В текущем дереве ветки нет ROM, CPU/PPU/APU, JSNES или другого эмулятора. Оригинал использовался отдельно как эталон при разработке. JSON содержит нормализованные данные карт, объектов, сценариев, текста и коллизий; исходные пиксели и исполняемая программа в сборку не входят. Старые коммиты репозитория относятся к предыдущей эмуляционной реализации.

## Запуск

Node.js 20+, установка зависимостей не требуется:

```sh
npm start
# http://localhost:4173
```

```sh
npm test
npm run audit
npm run build
```

`dist/` — самостоятельная статическая версия. Её можно разместить на обычном веб-сервере. Исходный файл игры для запуска и тестов не нужен.

## Управление

- Меню: ↑/↓ или Tab — выбор, Enter — подтвердить.
- Движение: стрелки/WASD. X — пушка. Z + направление — башня и пулемёт.
- Enter — игровая пауза. Tab — мастерская; в ней стрелки выбирают предмет, X переключает его.
- Радио: X/Z — следующее сообщение, Enter/Tab — закрыть.
- Пароль: семь цифр игровыми кнопками или через поле под экраном.
- На экране есть сенсорные кнопки; подключён стандартный Gamepad API.

Вкладки «Контроллер», «Данные карт» и «Новые персонажи» остаются диагностическими просмотрами.

## Новое оформление

Сгенерированы атласы игрушечной машины и башни, роботов, дрона, лодки, бонусов, эффектов, крупных машин и сооружений. Новые поверхности включают солнечную дорожку, траву, бирюзовую воду, лавандовый камень, розовый пол и цветочную поляну. Названия и текст интерфейса рисуются кодом, отдельно от изображений.

`src/music.js` содержит новую мелодию, четыре варианта аранжировки и звуковые эффекты Web Audio. Исходные изображения, музыка и звуковой движок не используются. Логическая видимость объектов хранится отдельно: изменение нового рисунка не меняет случайную последовательность и коллизии.

## Граница готовности

Остаются полное непрерывное прохождение всех ветвей, более широкая проверка редких сочетаний снаряжения, согласование задержек экранных переходов/аудиосигналов и длительная проверка оформления арен на разных устройствах. `campaignIntegrationComplete` остаётся `false`, PR — черновиком; `main` автоматически не заменяется.
