# Нативный перенос PortNES — работа не завершена

Это отдельная ветка разработки настоящего переноса на JavaScript. **Полной игры здесь ещё нет.** Враги, урон, оружие и прохождение кампании не восстановлены полностью. Проверочный интерфейс показывает только перенесённый контроллер, просмотр геометрии карт, новые спрайты и новую музыку.

В текущем дереве ветки нет картриджа, исполнения машинной программы, CPU/PPU/APU, JSNES или другого эмулятора. Оригинальная программа использовалась отдельно при разработке как эталон. В проект включены обычные JSON-данные геометрии, сценариев и объектов; они не содержат PRG/CHR или исходных пикселей. Старые коммиты репозитория относятся к предыдущей эмуляционной реализации.

## Запуск

Node.js 20+, без установки пакетов:

```sh
npm start
# http://localhost:4173
```

```sh
npm test
npm run audit
npm run build
```

`dist/` — самостоятельный статический просмотрщик проверяемых модулей. Ему не нужен исходный файл игры. Это **не дистрибутив завершённого порта**.

## Новое оформление

Сгенерированы отдельные спрайты игрушечной машины, её башни, роботов, дрона, лодки, бонуса и эффекта. Машина и башня поворачиваются независимо. Новые поверхности: солнечная дорожка, трава, бирюзовая вода, лавандовый камень, розовый пол и цветочная поляна.

В `src/music.js` написаны новая мелодия и эффекты через Web Audio. Исходная музыка и звуковой движок не используются. Режим карты окрашивает флаги геометрии; он не является законченным художественным оформлением всех уровней.

## Дальнейшая работа, необходимая для полного порта

Переведены **все 64 обработчика исходной таблицы**: 60 содержательных и четыре пустых. Это полнота таблицы обработчиков, а не готовность игры. Проверки боссов, связанных объектов и сцен описаны в [boss-evidence.md](docs/boss-evidence.md). Поле `campaignIntegrationComplete` в отчёте остаётся `false`.

Остаются полная интеграция боя и оружия игрока, предметы, подключение боссов к полному прохождению, подключение прокрутки и появления врагов к общему циклу, события страниц, радио, меню снаряжения, пароли, переходы и концовка. Только после их переноса и сравнения полного прохождения можно оценивать выполнение требования «один в один».

Изменения карты и общий проход камеры перенесены в `src/map-changes.js` и `src/camera.js`. Подключение к подсистеме объектов и ограничения сверки описаны в [map-camera-evidence.md](docs/map-camera-evidence.md). Всего 42 нативных теста.
