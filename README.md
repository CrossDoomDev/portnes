# Iron Tank · PortNES

Браузерная адаптация **Iron Tank: The Invasion of Normandy (USA)** из приложенного пользователем файла. HTML, CSS, JavaScript; без сервера игры, npm-зависимостей, CDN и внешних шрифтов.

**Это эмуляционная адаптация, а не независимый перенос исходной игровой логики на JavaScript.** JSNES исполняет оригинальную программу NES. Новый рендер использует сгенерированные материалы и сохраняет силуэты исходных тайлов. Полной перерисовки всех спрайтов и независимой переписи движка здесь нет. Стопроцентное совпадение с аппаратной NES на всём прохождении не подтверждено.

## Запуск

Нужен Node.js 20 или новее. Устанавливать пакеты не требуется:

```sh
npm start
```

Открыть `http://localhost:4173`. Картридж уже включён в `rom/iron-tank.nes`; повторно выбирать файл не нужно. Двойной щелчок по `index.html` не подходит: браузер должен загружать ES-модули через HTTP.

```sh
npm test
npm run build
node scripts/serve.mjs --directory dist --port 4173
```

В `dist/` получается полностью статическая версия. Её можно разместить на любом статическом хостинге, в том числе в подкаталоге. На HTTPS и localhost Service Worker сохраняет ресурсы для последующего запуска без сети.

## Управление

| Действие                         | Клавиатура                        | Кнопка NES |
| -------------------------------- | --------------------------------- | ---------- |
| Движение                         | Стрелки или WASD                  | D-pad      |
| Пушка                            | X или K                           | A          |
| Пулемёт                          | Z или J                           | B          |
| Направление башни                | Удерживать Z и нажать направление | B + D-pad  |
| Карта, предметы, радио           | Shift или Tab                     | Select     |
| Начало / пауза оригинальной игры | Enter                             | Start      |
| Пауза браузерной версии          | Esc                               | —          |
| Сохранить / загрузить            | F5 / F8                           | —          |
| Звук / полный экран              | M / F                             | —          |

Сенсорная крестовина поддерживает диагонали и несколько одновременных касаний. Стандартный браузерный геймпад: A/B, D-pad или левый стик, Select/Back и Start. Физический геймпад в этой сессии не проверялся.

«Начать операцию» отправляет обычный Start оригинальной игре. «Открыть меню оригинальной игры» позволяет выбрать в том числе ввод пароля. Загрузка браузерного сохранения оставляет игру на паузе до нажатия «Продолжить». Один слот хранится в IndexedDB; очистка данных сайта удалит его.

## Сохранение поведения

- Включён **весь исходный ROM**: 131 072 байта PRG и 131 072 байта CHR, mapper 1 / MMC1. Данные уровней, противников, предметов, сообщений и концовки не сокращались.
- CPU, PPU, APU и MMC1 исполняются локально ядром JSNES 2.1.0. Его исходники включены без изменений в `vendor/jsnes/`.
- Рендер только читает итоговый кадр и данные PPU. Он не патчит программу, RAM, столкновения, урон, скорость движения, RNG или игровые палитры.
- Игровой таймер работает с частотой NTSC около 60,099 Гц независимо от частоты дисплея. Отрисовка отделена от симуляции. При уходе из окна игра приостанавливается, кнопки отпускаются.
- Оригинальная музыка и эффекты поступают из APU. На HTTPS используется AudioWorklet; для обычного HTTP предусмотрен совместимый аудиовывод.
- Исходное изображение доступно в переключателе для сравнения.

SHA-256 приложенного картриджа проверяется при каждом запуске:

```text
e219538626a929b5b6c570b9b2d9843afba171d3032de0bd3122f38077a71184
```

## Новая графика

`assets/normandy.webp` — сгенерированная иллюстрация стартового экрана.

`assets/materials.webp` — сгенерированный атлас из шести поверхностей: песок, трава, вода, камень, броневая сталь и пепел. Он используется непосредственно в игре. WebGL добавляет текстуры, сглаживание углов Scale2x, освещение граней и небольшие визуальные тени. Для программного WebGL и устройств без WebGL автоматически используется Canvas 2D с теми же материалами и новой палитрой.

Размер кадра исходной игры остаётся 256 × 240. WebGL рисует его в 512 × 480; экран по умолчанию имеет телевизионное соотношение 4:3. На телефоне используется более компактная компоновка. Все игровые надписи и силуэты исходных объектов сохраняются: материалы не являются полным набором заново нарисованных спрайтов.

Описание происхождения изображений: [assets/ART.md](assets/ART.md).

## Проверка

Автоматические тесты проверяют:

1. Идентичность приложенного ROM, MMC1 и контрольную сумму, включая программный SHA-256 для обычного HTTP.
2. Одинаковое количество кадров на дисплеях 30, 60, 120 и 144 Гц.
3. Ограничение догоняющих кадров после задержки и сброс таймера при паузе.
4. Совместную работу клавиатуры, сенсорных кнопок и геймпада без взаимного сброса удерживаемых кнопок.
5. Идентичность CPU, mapper, PPU и аудио исходной и новой отрисовки на записи из 2100 кадров: заставка, брифинг, высадка, движение, поворот, стрельба и Select.
6. Восстановление состояния и дальнейшее совпадение памяти CPU и изображения.

Это регрессионная проверка относительно неизменённого JSNES. Она не доказывает полное совпадение эмуляции с реальной NES. Полное прохождение до концовки в этой сессии не выполнено.

## Структура

```text
index.html, styles.css    интерфейс и адаптивная компоновка
src/main.js              запуск, пауза, ввод, сохранения
src/clock.js             фиксированный таймер NTSC
src/input.js             объединение устройств ввода
src/renderer.js          WebGL и Canvas 2D
src/materials.js         сопоставление материалов без изменений игры
src/audio*.js            вывод оригинального звука
src/storage.js           IndexedDB и проверка сохранений
vendor/jsnes/            исходное ядро JSNES 2.1.0
rom/iron-tank.nes        картридж из задания
assets/                 сгенерированные изображения
tests/                  проверки
scripts/                локальный HTTP-сервер и статическая сборка
```

Источники: [JSNES](https://github.com/bfirsh/jsnes), [скан оригинальной инструкции SNK, стр. 5](https://www.nesfiles.com/NES/Iron_Tank/Iron_Tank.pdf). Сведения о сторонних материалах — [THIRD_PARTY.md](THIRD_PARTY.md).
